## FEATURE 1: LIGHT / DARK MODE 🌓
├─ Location: Settings panel (⚙️ button - top right)
├─ Implementation: CSS variables + dark-mode class
├─ Storage: localStorage (persists across sessions)
├─ UI Adapts:
│  ├─ Background: Light (#fff) ↔ Dark (#1a202c)
│  ├─ Text: Dark (#2d3748) ↔ Light (#e2e8f0)
│  ├─ Accent: Blue → Purple in dark mode
│  └─ All inputs, buttons, cards adapt automatically
├─ Toggle Style: Modern switch component
└─ Accessibility: Keyboard navigable, WCAG compliant

## FEATURE 2: CUSTOM GREETING NAME 👋
├─ Location: Settings panel → "Greeting Name" input
├─ Functionality:
│  ├─ Add your name (max 50 characters)
│  ├─ Greeting updates: "Good Morning, [Name]"
│  ├─ Updates in real-time
│  └─ Persists across sessions
├─ Display: Shows in greeting section with time
├─ Storage: localStorage ('dashboard-settings')
└─ Example: "Good Afternoon, Alex" @ 2:30 PM

## FEATURE 3: CUSTOMIZABLE POMODORO DURATION ⏱️
├─ Location: Settings panel → "Pomodoro Duration" input
├─ Adjustments:
│  ├─ Range: 1-60 minutes
│  ├─ Default: 25 minutes (traditional Pomodoro)
│  ├─ Input type: Number spinner
│  └─ Changes apply immediately
├─ Timer Reset: Automatically resets with new duration
├─ Storage: localStorage ('dashboard-settings')
├─ Use Cases:
│  ├─ 25 min: Traditional Pomodoro
│  ├─ 15 min: Quick focus session
│  ├─ 45 min: Deep work session
│  └─ Custom: Your preference
└─ Dynamic: CONFIG.TIMER_DURATION uses live value

## USAGE GUIDE:

1. ACCESSING SETTINGS
   └─ Click ⚙️ button (top-right corner)

2. TOGGLING DARK MODE
   └─ Check/uncheck "Dark Mode" toggle
   └─ Changes apply instantly
   └─ All UI adapts automatically

3. SETTING CUSTOM NAME
   └─ Type name in "Greeting Name" field
   └─ Max 50 characters
   └─ Greeting updates immediately
   └─ Example: "Good Morning, Sarah"

4. CHANGING TIMER DURATION
   └─ Enter minutes (1-60)
   └─ Timer resets with new value
   └─ Works for current and future sessions
   └─ Quick presets: 5, 15, 25, 45, 60

5. CLOSING SETTINGS
   └─ Click ✕ button
   └─ Click outside panel
   └─ Press Escape
